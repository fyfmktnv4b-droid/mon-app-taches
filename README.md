# Mon App Tâches

PWA de planification matinale : capture rapide de tâches, tri via une matrice urgent/important (Eisenhower), 3 priorités du jour mises en avant automatiquement. Synchronisée entre appareils via Supabase, avec rappels par notification push.

Le design est en cours de finalisation (voir la conversation Claude Code) ; le document de spec suivra dans un prochain commit.
